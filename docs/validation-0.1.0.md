# 0.1.0 검증 범위

2026-09-16, Windows / Python 3.12에서 코드 전용 wheel을 새 환경에 설치하고
사용자의 로컬 비전 자원을 별도로 설치해 확인했습니다. 게임 자료나 판독 결과는
이 문서와 소스·배포본에 포함하지 않습니다.

- 소스와 설치본: 각각 232개 테스트 통과, 10개 건너뜀. 건너뜀은 비공개 예제 이미지가
  필요한 기존 검사 9개와 Torch가 없는 실행 환경의 학습 테스트 모듈 1개입니다.
- Pyright 오류 0, 관련 코드 Ruff, sdist→wheel 빌드, 자원 혼입 검사, Twine strict 통과.
- 새 설치본에는 Torch·TorchVision·EasyOCR가 없으며 게임 이미지·학습 모델도 없습니다.
- 실제 학생 영상 3.4초 구간과 그 프레임 이미지 목록에서 각각 3명×19필드=57/57의 값과
  확정 상태가 기존 정답에 일치했습니다. HTTP 요청은 0건입니다.
- 인벤토리 원본 25칸은 아이템·티어·수량 표기가 모두 일치했습니다. 원본과 6가지 변형
  (75/50% 축소, 125% 확대, JPEG quality 60, 밝기 75%, 여백·위치 이동)에서 검출 175/175,
  수량 표기 175/175, 아이템·티어 173/175입니다. JPEG의 2칸은 보류, 수용한 값의 오답은
  0개입니다. 수량 표기에는 7번의 축약 `13K`가 포함되며 숨겨진 실제 정수는 알 수 없습니다.

이는 개발에 사용한 자료와 파생 이미지의 회귀 평가입니다. 새로운 촬영, 다른 언어,
다른 아이템 구성이나 UI에 대한 일반화 평가가 아닙니다. 오프라인 참조가 없었던
useall 계열 아이콘 9종은 해당 원본에 없으며 인식 정확도를 확인하지 않았습니다.
다른 OS의 실제 영상·모델 실행도 이 로컬 평가 범위에 포함하지 않습니다.

로컬 자원 설치는 체크섬, 경로 탈출·심볼릭 링크·대소문자 충돌 거부, 손상된 업데이트의
기존 선택 보존, 중복 설치 재사용, 이전 버전 복귀, 자원 미설치 시 네트워크 요청이나
출력 생성 없이 실패하는 동작을 검사합니다. 생성 fixture 통과는 실제 인식 정확도의
대체 증거가 아닙니다. 원격 CI 결과는 GitHub Actions의 해당 커밋 실행 결과를 확인하세요.
